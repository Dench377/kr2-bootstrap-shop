## Способ подключения Bootstrap

В проекте реализовано **локальное автономное подключение Bootstrap** (дополнительное задание на повышенный балл по разделам 7 и 17 методических указаний):

Файлы фреймворка размещены непосредственно в папке проекта:
- Таблица стилей: `vendor/bootstrap/css/bootstrap.min.css`
- Скрипты интерактивности: `vendor/bootstrap/js/bootstrap.bundle.min.js`

### Порядок подключения файлов в HTML:
1. В секции `<head>` подключается локальный файл стилей Bootstrap:
   ```html
   <link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
   ```
2. Строго после Bootstrap подключается собственный файл переопределений:
   ```html
   <link rel="stylesheet" href="css/custom.css">
   ```
3. Перед закрывающим тегом `</body>` подключается бандл скриптов:
   ```html
   <script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
   ```

*(При необходимости проект также полностью совместим с CDN-подключением `https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/...`)*.

## Ответы на контрольные вопросы (Раздел 19 методических указаний)

### 1. Что такое CSS-фреймворк?
**Ответ:** CSS-фреймворк — это готовая библиотека предварительно написанных стилей, сетки верстки, типографики и переиспользуемых компонентов пользовательского интерфейса (кнопок, карточек, форм, навигации), предназначенная для ускорения и стандартизации фронтенд-разработки.

### 2. Почему Bootstrap выбран как основной вариант?
**Ответ:** Bootstrap — самый популярный, надежный и зрелый CSS-фреймворк в индустрии с подробной документацией, интуитивной 12-колоночной сеткой Flexbox, богатой компонентной базой и встроенной кроссбраузерной адаптивностью «из коробки» (mobile-first).

### 3. Какие альтернативные CSS-фреймворки допускаются?
**Ответ:** В соответствии с методическими указаниями к альтернативным фреймворкам относятся **Tailwind CSS** (утилитарный подход) и **Bulma** (чистый CSS на Flexbox без JS), при условии сохранения всех требований к сетке, формам, карточкам и навигации.

### 4. Для чего используется `container`?
**Ответ:** Класс `.container` задает базовую ширину контентной области с фиксированными максимальными значениями для каждого адаптивного брейкпоинта (sm, md, lg, xl, xxl), центрирует контент по горизонтали (`margin-left: auto; margin-right: auto`) и обеспечивает внутренние боковые отступы (padding).

### 5. Для чего используется `row`?
**Ответ:** Класс `.row` является непосредственным flex-контейнером для колонок сетки (`col-*`). Он компенсирует горизонтальные внутренние отступы колонок за счет отрицательных внешних отступов (`negative margins`) и управляет горизонтальным выравниванием и интервалами между колонками.

### 6. Для чего используются `col-*`?
**Ответ:** Классы семейства `col-*` определяют ширину колонок в рамках 12-колоночной сетки на различных контрольных точках экрана (например, `col-12` на мобильных, `col-md-6` на планшетах, `col-lg-4` на десктопах), обеспечивая адаптивное перестроение блоков.

### 7. Что такое 12-колоночная сетка Bootstrap?
**Ответ:** Это система верстки, разделяющая ширину родительского ряда (`row`) на 12 равных условных долей. Любой дочерний элемент может занимать от 1 до 12 долей (например, `col-6` занимает 50% ширины, `col-4` — 33.3%, `col-3` — 25%). Сумма колонок в одной строке обычно равна 12; если сумма превышает 12, лишние колонки переносятся на новую строку.

### 8. Для чего используются `g-*`, `gx-*`, `gy-*`?
**Ответ:** Это классы управления интервалами между колонками (gutters). Класс `g-*` задает горизонтальный и вертикальный отступ одновременно (от `g-0` до `g-5`), `gx-*` задает только горизонтальный промежуток между столбцами, а `gy-*` задает только вертикальный промежуток между рядами карточек.

### 9. Для чего используется `navbar`?
**Ответ:** Компонент `navbar` используется для создания адаптивной шапки сайта, содержащей логотип (бренд), навигационные ссылки, формы поиска, кнопки действий и автоматическое сворачивание меню в «гамбургер» при уменьшении ширины экрана.

### 10. Почему для мобильного меню нужен Bootstrap JS Bundle?
**Ответ:** Сворачивание и плавное раскрытие навигационного меню по клику на кнопку `.navbar-toggler` управляется JavaScript-плагином Collapse. Скрипт `bootstrap.bundle.min.js` отслеживает события клика по атрибутам `data-bs-toggle="collapse"` и динамически переключает CSS-классы `collapsing`, `collapse` и `show`.

### 11. Для чего используется `card`?
**Ответ:** Компонент `card` представляет собой гибкий и структурированный контейнер для отображения связанного контента (в частности, карточек товаров, преимуществ или отзывов). Он включает готовые элементы: изображение (`card-img-top`), тело карточки (`card-body`), заголовок (`card-title`), описание (`card-text`) и подвал (`card-footer`).

### 12. Для чего используется `badge`?
**Ответ:** Компонент `badge` используется для компактного визуального выделения статусов, категорий, численных счетчиков или меток (например, бейджи «Хит», «Новинка», «Скидка -15%», количество товаров в корзине).

### 13. Для чего используется `alert`?
**Ответ:** Компонент `alert` предназначен для вывода контекстных уведомлений, сообщений об успешном выполнении операции, предупреждений или информации об акциях с возможностью закрытия через кнопку `btn-close` (`data-bs-dismiss="alert"`).

### 14. Для чего используется `modal`?
**Ответ:** Компонент `modal` создает диалоговое окно, всплывающее поверх основного содержимого страницы с затемнением фона (backdrop). Используется для сценариев, требующих фокусировки внимания пользователя: быстрой заявки, покупки в 1 клик или подтверждения действий.

### 15. Какие атрибуты нужны для открытия модального окна?
**Ответ:** Для открытия модального окна без написания кастомного JS на кнопку или ссылку вешаются data-атрибуты:
1. `data-bs-toggle="modal"` — указывает плагину Bootstrap, что клик вызывает модальное окно;
2. `data-bs-target="#idМодалки"` — селектор целевого блока модального окна, которое необходимо открыть (например, `data-bs-target="#quickOrderModal"`).

### 16. Для чего используются `form-control`, `form-select`, `input-group`, `form-check`?
**Ответ:** 
- `form-control` — стилизует текстовые поля ввода (`<input>`, `<textarea>`), обеспечивая полную ширину, единые отступы, границы и фокусную подсветку.
- `form-select` — стилизует выпадающие списки (`<select>`) с кастомной стрелкой выбора.
- `input-group` — объединяет поле ввода с текстовыми префиксами/суффиксами (например, префикс `+7` для телефона) или кнопками в одну цельную строку.
- `form-check` — контейнер для кастомных чекбоксов (`form-check-input`) и радиокнопок с их текстовыми метками (`form-check-label`).

### 17. Чем CDN-подключение отличается от локального подключения Bootstrap?
**Ответ:** При CDN-подключении файлы загружаются со сторонних серверов доставки контента (например, jsDelivr). Это экономит место в репозитории, но делает проект зависимым от интернет-соединения и доступности стороннего сервера. При локальном подключении скомпилированные файлы фреймворка хранятся непосредственно в папке проекта (`vendor/bootstrap/`), что обеспечивает полную автономность, независимость от сети и стабильность работы.

### 18. Какие файлы нужны для локального подключения Bootstrap?
**Ответ:** Минимально необходимы два скомпилированных файла:
1. Таблица стилей: `vendor/bootstrap/css/bootstrap.min.css`;
2. JavaScript-бандл (включающий Popper.js): `vendor/bootstrap/js/bootstrap.bundle.min.js`.

### 19. Почему `custom.css` должен подключаться после Bootstrap?
**Ответ:** В соответствии с правилами каскада CSS (Cascading Style Sheets) при равной специфичности селекторов приоритет имеет правило, объявленное ниже в коде. Подключение `custom.css` строго после `bootstrap.min.css` позволяет разработчику предсказуемо переопределять стили фреймворка без использования антипаттерна `!important`.
